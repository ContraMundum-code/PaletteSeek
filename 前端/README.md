# PaletteSeek 前端

这是 PaletteSeek 的 `Streamlit` 单页前端。

当前前端已经完成的核心主流程包括：

- 关键词检索、颜色检索、混合检索
- 筛选条件联动
- 结果卡片展示
- 详情区域展示
- 分析报告切换展示
- 取色盘输入、结果数量输入、滚动定位等基础交互

后续更值得投入的方向主要是：

- 结果区视觉统一
- 详情区信息层级再整理
- 交互稳定性和可维护性提升
- 性能和可读性优化

## 交付目标

- 三种检索方式可稳定运行

- 页面适合课堂展示和答辩演示

## 运行方式

```bash
pip install -r 前端/requirements.txt
streamlit run 前端/app.py
```

## 目录约定

- 后端数据和代码仍放在 `后端/paletteseek_backend/`
- 前端页面入口是 `前端/app.py`
- 色卡图片默认从 `后端/paletteseek_backend/color_cards/` 读取

## 说明

前端会直接调用 `PaletteSeek`，不额外增加 API 层。
