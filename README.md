# PaletteSeek

已部署可访问：
https://paletteseek.streamlit.app/

## 项目简介

PaletteSeek 是一个视觉艺术色彩分析平台。

系统能够从绘画、电影海报与视觉艺术作品中提取：

- 色盘（Color Palette）
- 风格标签（Style Tags）
- 关键词（Keywords）
- 色彩统计特征

并构建可浏览、可检索、可比较的灵感档案库。


## 技术栈

- Python
- Streamlit
- Pandas
- OpenPyXL
